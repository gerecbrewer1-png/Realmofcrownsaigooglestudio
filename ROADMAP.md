# Project Roadmap & Phases

- [x] **Phase 0: Foundation**: Full-stack framework (Express + Vite + React 19 + Tailwind), Firebase Firestore integration, secure architecture, core documentation suite.
- [x] **Phase 1: First Playable Kingdom**: Player account provisioning, dynamic resource simulation, data-driven buildings (Castle, Farms, Mines, Barracks, etc.), construction timers, speedups, starter package, quest milestones, and inventory.
- [x] **Phase 2: Persistent World Map & Living World / Naval Voyage**: Hexagonal coordinates, resource gathering nodes, barbarian camps, fog of war, army march routing, living Citadel environment, and 3D naval voyage renderer with ship LOD & instancing.
- [x] **Phase 3: Military & Combat / Adaptive Controls**: Tiered infantry, archers, cavalry, tactical 3D battlefield arena, reinforcement waves, conflict-free adaptive controls (WASD/touch/RTS hotkeys), hero Citadel click-to-move pathing, and coordinated wildlife pack hunting.
- [ ] **Phase 4: Hero Commanders & Research (NEXT ACTIVE PHASE)**: Commander progression, talent skill trees (Warlord, Guardian, Ranger, Steward, Strategist), equipment slots, and Academy scientific research tree.
- [ ] **Phase 5: Alliances & Global Chat**: Guilds, alliance technologies, rally attacks, territory expansion, and real-time moderated chat.
- [ ] **Phase 6: Events & World Bosses**: Automated server events, weekend tournament leaderboards, and world boss raids.
- [ ] **Phase 7: Store & In-App Purchases**: Cross-platform purchase verification, battle passes, and cosmetic customization.
- [ ] **Phase 8: Advanced LiveOps Admin Deck**: Real-time player inspection, compensation distribution, and economy re-balancing.
- [ ] **Phase 9: Scalability & Performance**: Caching layers, Redis/Firestore optimizations, and load testing.
- [ ] **Phase 10: Dedicated Mobile Apps**: Native Android (Jetpack Compose) and iOS (SwiftUI) wrappers sharing the unified backend.
